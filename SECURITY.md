# Security

## Reporting a vulnerability

Please report security issues **privately**, not in a public issue. Use this repository's **Security → Report a vulnerability** option, or reply to your invite message.

Include what you found, how to reproduce it, and the ONYX version (shown in **Settings → About**).

## How ONYX handles your data

See [Privacy and security](README.md#privacy-and-security) in the README. In short: seller data stays in a local database on your PC, the only network use is licensing, and licenses are verified on your PC against the ONYX license server's signature.

## Supported versions

During the beta, only the latest version receives fixes.
